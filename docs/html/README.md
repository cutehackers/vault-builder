# Design Pages

Builder-only reference pages. `init-vault.sh` does not copy this folder into new vaults.

- [project-memory-structure.html](project-memory-structure.html) - 프로젝트 메모리 구조 설계. L1 자동 메모리, L2 vault, L3 프로젝트 요약의 흐름, 설치·삭제 원칙, 실행 순서(1단계 builder 기반 정리, 2단계 메모리 기능, 3단계 Vault Graph)를 설명한다. 브라우저로 열어서 본다.
- [vault-roadmap.html](vault-roadmap.html) - Vault 개선 로드맵. OpenWiki 조사와 개선안 검토를 합친 제안 13개, 단계별 의존 관계, 결정 4개, 구현 상태(제안11~13 완료)를 보여준다. 2026-10-29 artifact에서 내보냈다.
- [vault-structure-map.html](vault-structure-map.html) - Vault 구조 지도. vault 하나의 폴더 구성, 여러 vault가 저장소와 연결되는 방식, `/project-memory`·MCP·메모 정리·install 흐름을 지금 구조와 이전 구조로 나눠 보여준다. 2026-10-29 artifact에서 내보냈다.
