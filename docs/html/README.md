# Design Pages

Builder-only reference pages. `init-vault.sh` does not copy this folder into new vaults.

- [project-memory-structure.html](project-memory-structure.html) - 프로젝트 메모리 구조 설계. L1 자동 메모리, L2 vault, L3 프로젝트 요약의 흐름, 설치·삭제 원칙, 실행 순서(1단계 builder 기반 정리, 2단계 메모리 기능, 3단계 Vault Graph)를 설명한다. 브라우저로 열어서 본다.
- [vault-roadmap.html](vault-roadmap.html) - Vault 개선 로드맵. 제안 14개, 단계별 의존 관계, 결정 4개와 2026-11-18 기준 구현 상태를 보여준다. 제안11~14는 완료, 제안2는 일부 완료, 제안1·3·4·8은 미착수이고, 릴리스 1.0.0~5.1.0에 들어간 기능 표가 있다.
- [vault-structure-map.html](vault-structure-map.html) - Vault 구조 지도. vault-builder 5.1.0(contract 6) 기준으로 vault 하나의 폴더 구성, vault 역할, machine에 하나씩 있는 파일, 자동으로 도는 흐름(세션 시작, 세션 수집, MCP 호출, 기억 제안 검토)을 보여준다.
